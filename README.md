# Student Management System

A console-based Student Management System developed in C++.

## Features

- Add student records
- Display student records
- Search students by name or roll number
- Update department and CGPA
- Delete student records
- Save student data to a text file
- Load student data from a text file

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- STL Vector
- File Handling
- Dev-C++

## Concepts Practiced

- Classes and Objects
- Encapsulation
- Vectors
- Loops and Conditional Statements
- Functions
- File Input/Output
- Searching and Updating Records

## How to Run

1. Download or clone this repository.
2. Open `StudMang.cpp` in a C++ IDE.
3. Compile the program.
4. Run the program.

## Note

This project is designed as a learning project for practicing C++ programming and Object-Oriented Programming.
